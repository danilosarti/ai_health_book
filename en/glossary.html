Appendix C: Glossary

Each term links to the chapter, and where possible to the definition, in which it is introduced. Terms are listed alphabetically; the short meanings are reminders, and the chapter gives the full definition.

Term Short meaning Defined in
Accuracy Proportion of instances classified correctly Ch. 5
Activation function (ReLU) Turns a neuron’s weighted sum into its output: step, sigmoid or the rectified linear unit \(\max(0, z)\) Ch. 7
Adjusted Rand index (ARI) Agreement between two partitions over all pairs of instances, corrected for chance; 1 = identical Ch. 11
Agent and environment Whatever chooses the actions, and everything it acts on but cannot fully control Ch. 14
AI Act risk tiers The EU classification of AI uses: prohibited, high-risk, transparency obligations, minimal risk Ch. 19
Artificial intelligence (AI) Systems that perform tasks that would require cognition if done by humans Ch. 1
Artificial neuron (perceptron) Multiplies its inputs by weights, adds a bias and passes the sum through an activation function Ch. 7
Attention Builds a new representation for a position as a weighted average of the positions it may look at; the weights \(\alpha_{ts}\) sum to 1 Ch. 17
Autoencoder An encoder that compresses an example to a short code and a decoder that reconstructs it Ch. 20
Automation bias The tendency to over-rely on an automated system’s output Ch. 19
Average treatment effect (ATE, CATE) \(\mathbb{E}[Y(1)] - \mathbb{E}[Y(0)]\) in a population; the CATE is the same contrast within a subgroup Ch. 13
Backdoor criterion A set of variables suffices for adjustment if it blocks every backdoor path and contains no descendant of the treatment Ch. 13
Backpropagation Computes the gradient of the loss for every weight by applying the chain rule from the output back to the input Ch. 7
Bag of words Describes a document by how often each vocabulary word occurs, ignoring order; stacked, the vectors form a document-term matrix Ch. 15
Bagging Fits one model per bootstrap sample and averages their predictions (bootstrap aggregating) Ch. 6
Baseline model The simplest sensible prediction (the training mean, or current practice) that any model must beat Ch. 3
Batch and epoch The subset of instances used for one gradient step, and one complete pass through the training set Ch. 7
Bayes’ theorem Rule that updates a prior probability with evidence: posterior ∝ likelihood × prior Ch. 2
Bayesian additive regression trees (BART) A sum of small trees with priors favouring shallow trees, fitted by MCMC; gives predictions with uncertainty Ch. 8
Bayesian regression A regression whose coefficients receive priors; the result is their joint posterior rather than single estimates Ch. 8
Benchmark and real-world evaluation A fixed public test set, versus testing the whole system on the tasks, documents and users where it will be deployed Ch. 19
Bias (of a model) Systematic error from assumptions that are too rigid; leads to underfitting Ch. 1
Bootstrap sample \(n\) instances drawn at random with replacement from a dataset of \(n\) Ch. 6
Byte-pair encoding (BPE) Builds a subword vocabulary by repeatedly merging the most frequent pair of adjacent symbols Ch. 15
Calibration Agreement between predicted probabilities and observed frequencies Ch. 5
Causal mask Stops each position from attending to later positions, so a model can generate text left to right Ch. 17
Centroid and medoid The mean of a cluster’s members (a synthetic point), and the member closest on average to all the others (a real one) Ch. 11
Chain rule of probability The probability of a sequence is the product of each token’s probability given the previous ones Ch. 16
Classification Supervised learning with a categorical outcome Ch. 1
Classification threshold Probability \(t\) above which a case is classified as positive; a choice of use, not a property of the model Ch. 5
Cluster and clustering A group of instances more similar to one another than to others; clustering finds such groups without labels Ch. 11
Coefficient (regression) Expected difference in the outcome per unit of a predictor, other predictors held fixed; an association, not necessarily an effect Ch. 4
Coefficient of determination (\(R^2\)) One minus the ratio of the model’s squared error to that of a baseline predicting the mean Ch. 3
Coefficient path Each coefficient of a regularised model drawn as a function of \(\lambda\) Ch. 4
Collider A variable caused by two others on a path; adjusting or selecting on it creates a spurious association Ch. 13
Collinearity One feature can be written, exactly or nearly, as a weighted sum of others; the features carry overlapping information Ch. 10
Complete-case analysis Keeps only the rows in which every variable used is observed (listwise deletion) Ch. 9
Confidence interval A range computed so that, over many repetitions of the study, 95 % of such ranges would contain the true value Ch. 4
Confounder A common cause of a treatment (exposure) and an outcome; it opens a backdoor path Ch. 13
Confusion matrix Cross-table of predicted and actual classes: true and false positives, false and true negatives Ch. 5
Conjugate prior A prior that gives a posterior of the same family (beta prior with a yes/no likelihood) Ch. 8
Convolution Slides a small filter of learned weights across an image, producing a feature map Ch. 7
Convolutional neural network (CNN) Stacks convolution, activation and pooling blocks, followed by fully connected layers Ch. 7
Cosine similarity Cosine of the angle between two vectors; for documents, 0 = no word in common, 1 = same proportions Ch. 15
Cost-complexity pruning Cuts back a tree by charging a price \(c_p\) for every leaf Ch. 6
Counterfactual A statement about what would have happened under an intervention that did not take place Ch. 13
Counterfactual explanation A small change in the inputs that would change the model’s output in a specified way; describes the model, not the patient Ch. 12
Credible interval An interval containing 95 % of the posterior probability: given model, priors and data, the parameter lies inside with 95 % probability Ch. 8
Cross-entropy Average surprise when outcomes from \(P\) are predicted with a model \(Q\); the training loss of language models Ch. 16
Cross-validation Repeatedly holding out part of the training data to estimate performance Ch. 1
Curse of dimensionality As dimensions grow, data become sparse and distances concentrate, so neighbourhood methods need far more data Ch. 10
Data Recorded representations of facts, observations or measurements Ch. 1
DBSCAN Density-based clustering: grows clusters from core points with at least minPts neighbours within radius \(r\); other points are noise Ch. 11
Decision Choice of one alternative from a set, given a state of knowledge Ch. 1
Decision basis Explicit alternatives, consequences, preferences and uncertainties of a decision Ch. 1
Decision threshold Probability at which two alternatives have equal expected value Ch. 1
Decision tree Predicts by a sequence of yes/no questions on the features, from the root node to a leaf Ch. 6
Decoding (temperature, top-k, top-p) Turning next-token probabilities into text: greedy choice or sampling, reshaped by temperature \(\tau\) and top-\(k\)/top-\(p\) Ch. 16
Design matrix Matrix with one row per instance and one column per coefficient, with 0/1 dummy columns for categories Ch. 4
Differential privacy A mathematical guarantee that the output changes little whether or not any one person’s data were used Ch. 20
Diffusion model Learns to reverse a process that gradually adds noise; generates by denoising pure noise step by step Ch. 20
Dimension (high-dimensional data) The number of features \(p\); data are high-dimensional when \(p\) is large relative to \(n\) Ch. 10
Directed acyclic graph (DAG) A diagram of causal assumptions: arrows for direct effects, no cycles; missing arrows are the strongest assumptions Ch. 13
Distance A rule turning two feature vectors into a non-negative number (Euclidean, Manhattan, cosine, Mahalanobis) Ch. 10
Distributional hypothesis Words that occur in similar contexts tend to have similar meanings Ch. 16
Dynamic treatment regime A sequence of decision rules mapping a patient’s history at each decision point to a treatment Ch. 14
Early stopping and dropout Keep the weights with the lowest validation loss; randomly switch off neurons during training. Both reduce overfitting Ch. 7
Elastic net A mixture of the lasso and ridge penalties, with mixing parameter \(\alpha\) from 0 (ridge) to 1 (lasso) Ch. 4
Embedding A dense vector of \(d\) learned numbers representing a token, a row of the embedding matrix Ch. 16
Encoder and decoder Stacks with bidirectional attention (contextual vectors) or causally masked attention (generation); joined by cross-attention Ch. 17
Entropy Expected surprise of a random variable, in bits; 0 when the outcome is certain Ch. 2
Expectation and variance Long-run average of a random variable, and the average squared distance from it (its square root is the standard deviation) Ch. 2
Expected loss Average loss of an action, each loss weighted by the probability of the state that produces it; choose the smallest Ch. 2
Expected value Average score of an alternative, weighting consequences by their probabilities Ch. 1
Experimental data Data generated when the investigator assigns exposures by design Ch. 1
Explainability Methods that build a separate, simpler description of a model’s behaviour Ch. 12
Explained variance (scree plot) Share of the total variance carried by each component, shown in order in a scree plot Ch. 10
Exploration and exploitation Trying uncertain actions to learn about them, versus choosing the action that looks best now Ch. 14
Feature A column (variable) of a dataset Ch. 1
Fidelity, diversity and privacy (of synthetic data) Synthetic records look real, cover the whole range of the real data, and reveal nothing about the individuals used for training Ch. 20
Fine-tuning (LoRA, distillation) Further training on target-task data; LoRA learns a small low-rank correction, distillation trains a small model to imitate a large one Ch. 19
Foundation model (LLM) A large model trained on broad data that can be adapted to many tasks; a large language model is one for text Ch. 19
Gaussian mixture model (GMM) Assumes each instance comes from one of \(K\) normal components chosen with probabilities \(\omega_k\) Ch. 11
Generalisation Good performance of a model on new, unseen data Ch. 1
Generative adversarial network (GAN) A generator that makes synthetic examples and a discriminator that tries to tell them from real ones, trained against each other Ch. 20
Generative and discriminative models Learning the distribution of the data, so new examples can be sampled, versus learning the outcome given the features Ch. 20
Generative modelling Learning the data distribution to create new, realistic examples Ch. 1
Global and local explanations Describe a model’s behaviour over a population, or one prediction for one individual Ch. 12
Gradient boosting Builds a model in rounds, each small tree fitted to the current residuals and added with a learning rate Ch. 6
Gradient descent Minimises a loss by repeatedly moving every weight a small step against its gradient Ch. 7
H statistic Share of the joint effect of two features not explained by their separate effects (Friedman–Popescu) Ch. 12
Hallucination Fluent, plausible content not supported by the source or the facts, including invented references Ch. 19
Hierarchical clustering (dendrogram) Repeatedly merges the two closest clusters; the merges form a tree, cut at a height to give a partition Ch. 11
Human oversight Designing a high-risk system so that competent people can understand, override and stop it Ch. 19
Hyperparameter A setting that controls how a model is learned, chosen on data not used for fitting (tuning) Ch. 3
Impurity (Gini index) How mixed the outcomes in a node are: within-node variance, Gini index or entropy; splits are chosen to reduce it Ch. 6
Instance A row of a dataset (a patient, a batch…) Ch. 1
Instruction tuning Further training on prompts paired with good responses written by people Ch. 19
Internal validation index (silhouette) Scores a partition from the data alone by balancing compactness and separation of the clusters Ch. 11
Interpretability A person can understand how a model works from its structure (a short equation, a small tree) Ch. 12
Intervention Setting a variable to a chosen value instead of letting it take its own value Ch. 13
Inverse probability weighting (IPW) Weights each patient by the inverse of the probability of the treatment received, creating a pseudo-population without confounding Ch. 13
\(k\)-means Alternates assigning each instance to the nearest centroid and moving centroids to the mean of their members Ch. 11
\(k\)-nearest neighbours (\(k\)NN) Predicts a new instance by averaging (or voting among) the \(k\) closest training instances Ch. 3
Kullback–Leibler divergence Cross-entropy minus entropy; zero only when the model equals the true distribution Ch. 16
Label The known value of the outcome for an instance Ch. 1
Language model A probability distribution over token sequences, given by next-token probabilities \(P_\theta(w_t \mid w_{<t})\) Ch. 16
Lasso Regularisation with the sum of absolute coefficients (L1 penalty); sets some coefficients exactly to zero Ch. 4
Latent variable An unobserved quantity that helps explain or generate the observed variables Ch. 20
Leakage Information unavailable at prediction time, or from the evaluation data, reaching the model during development; gives optimistic performance Ch. 3
Learning rate Step size \(\eta\) that scales each update in boosting and in gradient descent Ch. 6
Leverage and Cook’s distance How far an instance’s predictors lie from the others, and how much removing it would change the fit Ch. 4
Likelihood Probability of the observed data viewed as a function of the parameter; not the probability that the parameter is true Ch. 2
Linear regression Outcome written as an intercept plus a weighted sum of predictors plus error; linear in the coefficients Ch. 4
Logistic (sigmoid) function \(\sigma(z) = 1/(1+e^{-z})\), an S-shaped curve that turns any number into a probability Ch. 5
Logistic regression Models the probability of a binary outcome as \(\sigma(\beta_0 + \beta_1 x_1 + \dots)\): linear on the log-odds scale Ch. 5
Loss function The penalty \(\mathcal{L}(y, \hat y)\) for predicting \(\hat y\) when the truth is \(y\); fitting minimises its average Ch. 3
Machine learning (ML) AI that learns from data instead of explicit rules Ch. 1
Markov chain Monte Carlo (MCMC) Produces chains of draws whose distribution approaches the posterior; checked with trace plots, R-hat and effective sample size Ch. 8
Markov decision process (MDP) States, actions, transition probabilities and rewards, with the next state depending only on the current state and action Ch. 14
Masked and autoregressive language modelling Recovering hidden tokens from the rest of the text (BERT), versus predicting each token from the ones before (GPT) Ch. 17
Matching Pairs treated patients with similar untreated ones and compares outcomes within pairs; usually estimates the effect in the treated Ch. 13
Maximum likelihood estimate (MLE) The parameter value with the highest likelihood, \(\hat\theta\) Ch. 2
Mean absolute error (MAE) Average absolute distance between predictions and observed outcomes Ch. 1
Mean squared error (MSE) and RMSE Average squared prediction error, and its square root in the units of the outcome Ch. 3
Mediator A variable on the causal path from treatment to outcome; adjusting for it removes part of the effect Ch. 13
MICE (chained equations) Imputes several incomplete variables by cycling through them, each predicted from all the others Ch. 9
Missing at random (MAR) Given the observed data, the probability of a gap no longer depends on the unobserved values Ch. 9
Missing completely at random (MCAR) The probability of a gap depends on nothing in the data Ch. 9
Missing not at random (MNAR) The probability of a gap depends on the unobserved values themselves, even given the observed data Ch. 9
Missing value A value that was meant to be recorded but was not; the indicator \(R_{ij}\) records whether it was observed Ch. 9
Mode collapse A generator that produces only a few kinds of examples, missing much of the variety of the real data Ch. 20
Model A simplified, purpose-built representation of reality Ch. 1
Model-agnostic and model-specific methods Methods that only query a model’s predictions, versus methods that use its internal structure Ch. 12
Multi-armed bandit A repeated choice among actions with unknown mean rewards, with no state carrying over between rounds Ch. 14
Multi-head attention Several attention operations (heads) side by side, each with its own projections, their outputs concatenated Ch. 17
Multilayer perceptron (MLP) Neurons arranged in layers, each hidden layer applying weights and an activation to the previous layer’s output Ch. 7
Multiple imputation Creates \(M\) completed datasets with random draws for the gaps, analyses each and pools the results Ch. 9
n-gram model Assumes the next token depends only on the previous \(n-1\) tokens; probabilities estimated by counting Ch. 16
Natural language processing (NLP) The discipline that makes computers analyse and produce human language Ch. 15
Negation detection Deciding whether a mentioned finding is affirmed or negated, using trigger phrases and their scope Ch. 15
Nested cross-validation An outer cross-validation that estimates performance and an inner one that tunes hyperparameters, so tuning is included in the estimate Ch. 3
Net benefit and decision curve True positives minus false positives weighted by the threshold odds; plotted against the threshold, it shows whether a model is worth using Ch. 5
Observational data Data recorded as things happen, without intervention Ch. 1
Odds and log-odds \(p/(1-p)\), how many times more likely an event is than not; its logarithm is the logit Ch. 5
Odds ratio (OR) Ratio of the odds in two groups; in logistic regression \(e^{\beta_j}\) per unit of \(x_j\) Ch. 5
One-standard-error rule Choose the largest \(\lambda\) whose cross-validated error is within one standard error of the minimum Ch. 4
Ordinary least squares (OLS) Estimates the coefficients that make the residual sum of squares as small as possible Ch. 4
Out-of-bag (OOB) error Error of predictions made by the trees that did not see each instance; a nearly free estimate of test error Ch. 6
Outcome The feature we want to predict or explain (response, target) Ch. 1
Overfitting Following the noise of the training data; good training, poor test performance Ch. 1
p-value Probability of an estimate at least as far from zero as observed if the true value were zero and the assumptions held Ch. 4
Partial dependence and ICE curves How one patient’s prediction (ICE) or the average prediction (PDP) changes when one feature is varied Ch. 12
Permutation importance Average increase in error when one feature’s column is shuffled Ch. 12
Perplexity Two raised to the cross-entropy in bits: the effective number of equally likely choices at each step Ch. 16
Policy A rule for choosing actions from states, \(\pi(a \mid s)\) Ch. 14
Pooling Shrinks a feature map by summarising small blocks (maximum or average) Ch. 7
Positional encoding A vector added to each token embedding so the model knows where the token is Ch. 17
Posterior predictive distribution Distribution of a future outcome, averaging the model’s predictions over the whole posterior Ch. 8
Potential outcomes The outcomes a patient would have under each treatment, \(Y(1)\) and \(Y(0)\); only one is ever observed Ch. 13
Precision, recall and F1 Positive predictive value, sensitivity, and their harmonic mean Ch. 5
Precision–recall curve Precision against recall over all thresholds; informative when positives are rare Ch. 5
Prediction versus causation A model that predicts well need not tell us what would happen if we intervened Ch. 1
Predictive mean matching (PMM) Imputes by copying the observed value of a participant whose prediction is close; imputed values always occur in the data Ch. 9
Predictive values (PPV, NPV) Probability of having the condition after a positive test, and of not having it after a negative one Ch. 2
Predictor A feature used to make a prediction (input) Ch. 1
Preference tuning (RLHF, DPO) Training a model on human comparisons of responses, through a reward model and reinforcement learning or directly Ch. 19
Pretraining Fitting a language model to a very large corpus by minimising next-token cross-entropy Ch. 19
Prevalence Proportion of the population tested that has the condition; for one patient, the prior probability Ch. 2
Principal component analysis (PCA) Replaces correlated features by uncorrelated weighted sums ordered by the variance they carry Ch. 10
Prior and posterior distribution What is assumed about a parameter before the data, and what is known after: posterior ∝ likelihood × prior Ch. 8
Prior and posterior probability Probability of an event before and after seeing the evidence Ch. 2
Probability distribution The values a random variable can take and how probable each is; for a continuous variable, a density whose area gives probabilities Ch. 2
Prompt The text given to a language model as context; may include a system prompt, worked examples (few-shot) or a request to reason step by step Ch. 19
Propensity score A patient’s probability of receiving the treatment given covariates, \(e(\mathbf{x})\) Ch. 13
Q-learning Learns action values from experience by moving each estimate towards reward plus discounted best next value Ch. 14
Query, key and value Three learned projections of each token: what it looks for, what it offers to be found by, and the content it passes on Ch. 17
Random forest Bagged deep trees that consider only a random subset of \(m_{\text{try}}\) features at each split Ch. 6
Random variable A quantity whose value is not known in advance and is described by probabilities Ch. 2
Randomisation Assigning treatment by chance, so treated and untreated groups are exchangeable for measured and unmeasured characteristics Ch. 13
Recurrent neural network (RNN) Reads a sequence token by token, updating a hidden state with the same weights at every position Ch. 16
Regression Supervised learning with a numerical outcome Ch. 1
Regular expression A compact language for describing text patterns to find, extract or replace Ch. 15
Regularisation (shrinkage) Fitting with a penalty on the size of the coefficients, of strength \(\lambda\); adds bias, reduces variance Ch. 4
Reinforcement learning Learning a policy for acting from rewards over time Ch. 1
Reparameterisation trick Writing a random code as \(\mathbf{\mu} + \mathbf{\sigma} \odot \mathbf{\varepsilon}\) so gradients can flow through the sampling step Ch. 20
Reproducibility Others can rerun the analysis and obtain the same results Ch. 1
Residual Observed minus predicted outcome, \(e_i = y_i - \hat y_i\) Ch. 4
Residual connection and layer normalisation Adding a sublayer’s input to its output; rescaling each token vector to mean 0 and standard deviation 1 Ch. 17
Retrieval-augmented generation (RAG) A retriever finds the chunks most similar to a question, which are put into the prompt so the answer can be grounded in them Ch. 19
Return and discount factor The discounted sum of future rewards, \(G_t\); the discount factor \(\gamma\) sets how much later rewards count Ch. 14
Review queue Two thresholds on a classifier’s probability: clear below one, act above the other, send the rest to a person Ch. 15
Reward hacking An agent maximising a misspecified reward in ways its designers did not intend Ch. 14
Ridge regression Regularisation with the sum of squared coefficients (L2 penalty); shrinks all coefficients Ch. 4
ROC curve and AUC Sensitivity against 1 − specificity over all thresholds; the area under it is the probability that a case is ranked above a non-case Ch. 5
Rubin’s rules Pool multiply imputed results: average the estimates; add within- and between-imputation variance Ch. 9
Scores and loadings An instance’s coordinates on the components, and how strongly each feature relates to each component Ch. 10
Sensitivity analysis (δ-adjustment) Repeats an analysis under different assumptions, for example shifting imputed values by \(\delta\), to see whether the conclusion holds Ch. 9
Sensitivity and specificity Proportion of people with the condition who test positive, and of people without it who test negative Ch. 2
Shapley value A feature’s marginal contribution to one prediction, averaged over all orders in which features could be added Ch. 12
Shortcut learning Good performance obtained from features associated with the outcome but not its cause (a marker, a scanner); fails when the association changes Ch. 7
Single imputation Fills every gap once (mean, median, a prediction) and analyses the table as if fully observed Ch. 9
Skip-gram (word2vec) Learns embeddings by predicting the words within a small window around each word Ch. 16
Smoothing Adjusts count-based probabilities so no possible token has probability zero (add-\(\delta\)) Ch. 16
Soft assignment Posterior probability that an instance belongs to each component, instead of a single label Ch. 11
Softmax Turns a vector of scores into probabilities that add up to 1; the multi-class version of the logistic function Ch. 7
Software as a medical device Software intended by its manufacturer for a medical purpose such as diagnosis, prediction or treatment Ch. 19
Stacking A meta-model learns to combine the out-of-fold predictions of several base models Ch. 6
Standardisation Subtracting a feature’s mean and dividing by its standard deviation, so units no longer matter Ch. 10
State, action and reward What the agent observes at time \(t\), what it does, and the number that scores the consequence Ch. 14
Statistical model \(y = f(\mathbf{x}) + \varepsilon\): systematic part plus error Ch. 1
String and character encoding An ordered sequence of characters, and the mapping of characters to numbers and bytes (Unicode, UTF-8) Ch. 15
Supervised learning Learning a mapping from features to a known outcome Ch. 1
Synthetic data Data produced by a generative model rather than measured, meant to reproduce chosen properties of real data Ch. 20
t-SNE A nonlinear map that keeps neighbours together; distances between far-apart groups are not meaningful Ch. 10
Tensor An array of numbers with any number of axes; its shape lists the length of each axis Ch. 7
Test set Data kept aside to estimate performance on new cases Ch. 1
Text classifier A supervised model that maps a document vector to a probability for each class Ch. 15
TF-IDF Term frequency times inverse document frequency: weights words that are frequent in a document but rare in the collection Ch. 15
Thompson sampling Chooses each action with the posterior probability that it is the best, by drawing from each arm’s posterior Ch. 14
Token and vocabulary The unit a text is cut into (word, subword, character, byte), and the set of distinct tokens a system knows Ch. 15
Tool use and agent (LLM) The model writes requests executed by ordinary software; an agent also decides which steps and tools to use Ch. 19
Training set Data used to fit a model Ch. 1
Transfer learning Reusing a network trained on a large dataset as the starting point for a new task Ch. 7
Transformer block Multi-head attention and a feed-forward network, each with layer normalisation and a residual connection; a transformer stacks \(N\) blocks Ch. 17
UMAP Builds a nearest-neighbour graph and lays it out in few dimensions; settings n_neighbors and min_dist Ch. 10
Unsupervised learning Finding structure in data without an outcome Ch. 1
Validation set Data used to compare candidate models or settings and choose among them, before the test set is opened Ch. 3
Value function Expected return from a state, \(V^\pi(s)\), or from taking an action in a state, \(Q^\pi(s,a)\), under a policy Ch. 14
Value of information How much better a decision is expected to become if an uncertainty is resolved before deciding Ch. 2
Value-suppressing uncertainty palette (VSUP) A colour scale that merges shades as uncertainty grows, so only reliable values stand out Ch. 12
Vanishing gradient and LSTM Gradients shrink over many steps back in time; the LSTM adds a memory cell with gates to keep information longer Ch. 16
Variance (of a model) Sensitivity of a model to its particular training set Ch. 1
Variational autoencoder (VAE) An autoencoder whose code is sampled from a normal distribution, with a KL penalty that makes the code space suitable for sampling Ch. 20
Weakly informative prior A prior that only rules out implausible values Ch. 8
