Welcome

This is an interactive book. You will not only read it: you will fill in tables, answer quick questions, move sliders, and run and edit real R and Python code without installing anything. Every chapter is one step on the same road, from “what is a model?” to being able to judge whether an AI assistant should be trusted with a clinical decision.

The book at a glance

The idea that runs through the book

A model is only as good as the decision it improves.

Health care is full of decisions taken under uncertainty: whether to start a treatment tonight, which batch of a cell therapy to release, which patient to call first. Data describe what has happened; models turn data into information; people use that information to decide; and their decisions create new data. We call this the decision loop, and every chapter ends by asking where its method sits in the loop, what can go wrong, and who stays in control.

How to use this book

  • Read it your way. The chapters tell one story, from data to decisions to language models, and reading them in order is the smoothest route. But each chapter also stands on its own: it opens with a Starting here? box that recaps, in a few lines, everything it borrows from earlier chapters and reintroduces the running examples, and every technical term links back to its definition (hover over the link to see it without leaving the page).
  • Do the gate. Each chapter opens with a short task that checks you are ready. You can skip it.
  • Answer the quick checks. One question, a few options, and an explanation for every option, including the wrong ones. Wrong answers are part of learning; they cost you nothing.
  • Play with the “Try it” widgets. Change a number, watch a figure react.
  • Complete the missions. Short coding tasks, graded instantly in your browser. Each one has a hint and a solution. Choose R or Python with the tabs; your choice is remembered across the book.
  • Run the Lab. A longer piece of code at the end of each chapter, also downloadable as .R and .py scripts so you can run it on your own computer.
The code runs in your browser: what if it does not load?

The R and Python engines (webR and Pyodide) download the first time you press Run code, which can take 10–30 seconds on a slow connection. If they cannot load (for example on a locked-down network), the text, quick checks, gates and widgets still work, and every Lab can be downloaded and run in RStudio, Positron, VS Code or Jupyter.

Progress, stars and badges

Each chapter has a progress bar, named levels, stars (for questions answered right first time and missions solved without opening the solution) and a badge when you complete it. Your overview is below.

Privacy

Your answers and progress are stored only in this browser (local storage). Nothing is sent to the author or to any server. Clearing your browser data, using a private window or changing device starts you from zero. You can reset any chapter, or the whole book, at any time.

Who this book is for

Any health professional or student (in medicine, nursing, pharmacy, biomedical sciences, public health, therapeutic technologies and beyond) who wants to understand, use and question AI and machine learning with rigour. You need some basic statistics; you do not need to know how to program, and no prior knowledge of AI is assumed. The mathematics is there when it matters, introduced step by step: every term is defined the first time it is used, and the glossary is never more than a click away.

The data in this book

All datasets in this book are simulated: they look like real clinical data but describe no real person. That makes them safe to share (every dataset can be downloaded from the data appendix, together with the code that generated it), and it gives us a superpower real data never have: we know the truth, so we can check whether a method finds it.
